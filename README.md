# God's Grace Bakery

A fun static website showcasing a bakery's delicious offerings — cakes, breads, pastries, and cookies.

## Features

- Responsive design (mobile-friendly)
- Interactive menu with category filtering
- Smooth scroll navigation
- Scroll-reveal animations
- Warm bakery-themed color palette

## Getting Started

Open `index.html` in any browser — no build tools or dependencies required.

Alternatively, serve locally:

```bash
cd god-s-grace-bakery
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Tech Stack

- HTML5
- CSS3 (custom properties, grid, animations)
- Vanilla JavaScript (Intersection Observer, DOM filtering)
- Google Fonts (Playfair Display, Lato)
